## How to write a new ADR

1. Number it sequentially (`0012-...`), dated (`2026-MM-DD`), short title.
   **CLAIM THE NUMBER FIRST (rule added 2026-08-08):** before writing the body,
   add your row to the index table in THIS file and commit/push that one-line
   change (or, on a branch, verify the number against every OPEN PR's file list,
   not just `main`). "Next free on main" has now produced THREE collisions —
   `0067` ×2, `0069` ×3, and `0087` claimed by two same-day PRs (resolved by
   renumbering the later claim to `0088` pre-merge). A number is claimed by the
   first PUSHED reference to it, anywhere — not by the first file to reach main.
2. Use the template:
   - **Context** — what's the situation
   - **Decision** — what we chose
   - **Alternatives considered** — what we rejected and why
   - **Consequences** — what this commits us to
3. Once accepted, ADRs are immutable. To overturn one, write a new ADR that supersedes it.
4. Cross-reference the charter section that prompted the decision.
